# Отслеживание upstream

Часть компонентов Ready Set адаптирована из внешних проектов, которые могут
развиваться независимо. В [`tracking/`](tracking/) находятся описания
отслеживаемых репозиториев, а [`check.py`](check.py) сравнивает их ревизии и
сообщает об изменениях, требующих проверки.

Это средство сопровождения: каждое изменение upstream всё равно должно быть
рассмотрено и интегрировано обычным pull request.
