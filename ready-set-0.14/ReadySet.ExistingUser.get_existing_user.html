get_existing_user

Description:

public virtual ExistingUserStatus get_existing_user ()

Whether plugin support running without special permissuin for settings up current user.

Running without GUI, so can be synchronous. If plugin not realize this interface, application will use ReadySet.ExistingUserStatus.NO as status.

ReadySet.ExistingUserStatus.IF_NOT_PASSED by default.
