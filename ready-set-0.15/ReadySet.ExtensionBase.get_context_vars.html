get_context_vars

Description:

public virtual HashTable<string,ContextVarInfo> get_context_vars ()

Returns the context variables provided by this extension.

Override this method and add entries to the table returned by the base implementation: 

var vars = base.get_context_vars ();
vars["enabled"] = new ContextVarInfo (ContextType.BOOLEAN, true);
return vars;

The application registers the returned variables under the extension's module name. The default implementation returns a new empty table.

Returns:

a newly allocated table of variable names and their metadata
