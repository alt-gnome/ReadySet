Content:

Properties:

  • public string id { get; construct; }
    Id of stage. Stage can be marked as passed via InstallerProgressData.pass_stage. Stage next to it will be marked as InstallerStageState.CURRENT
  • public string name { get; construct; }
    Human readable name. It well be shown at stage list with it state in UI.
  • public double size { get; }
    The step size is relative to global progress. It can be from 0 to 1. The remaining progress will be divided between stages, where size is -1. It is advisable to leave at least one stage with the value - 1.
