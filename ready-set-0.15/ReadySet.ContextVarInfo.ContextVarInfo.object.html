ContextVarInfo.object

Description:

public ContextVarInfo.object (Type nested_object_type, Value? default_value = null)

Creates metadata for an object context variable.

`nested_object_type` must be a concrete ReadySet.ContextObject type. When supplied, `default_value` must contain an object of exactly that type.

Parameters:

nested_object_type

the concrete object type stored by the variable

default_value

the value restored by Context.reset, or `null` when the variable has no default
