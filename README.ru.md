Ready Set — модульное GTK-приложение. Последовательность его страниц собирается
из плагинов шагов, а параметры можно передать заранее в конфигурации, не
заставляя пользователя повторно вводить уже известные значения.

## Доступные шаги

Приложение собирается из плагинов шагов. Сейчас доступны следующие плагины:

- [дата и время](plugins/date-and-time/README.ru.md)
- [клавиатура](plugins/keyboard/README.ru.md)
- [язык](plugins/language/README.ru.md)
- [лицензионное соглашение](plugins/license-agreement/README.ru.md)
- [сеть](plugins/network/README.ru.md)
- [приватность](plugins/privacy/README.ru.md)
- [программное обеспечение](plugins/software/README.ru.md)
- [пользователь](plugins/user/README.ru.md) — собирается как `user-passwdqc` (по умолчанию) и/или `user-pwquality` в зависимости от опции сборки `password_check_backend`

Если первым выбранным шагом не реализован интерфейс `Welcome`, Ready Set
показывает собственную приветственную страницу.

Плагины установщика загружаются отдельно через опцию `--installer`. Их шаги
указываются с префиксом `installer.`, например `installer.example-step`.

## Режимы работы

Ready Set автоматически определяет режим работы:

- `installer` — если через `--installer` указан плагин установщика;
- `initial-setup` — если приложение запущено от имени пользователя `ready-set`
  или `gnome-initial-setup`;
- `existing-user` — если приложение запущено от имени обычного пользователя.

В сборках с `nightly=true` режим можно принудительно задать через
`--force-mode`.

## Конфигурация

Ready Set настраивается через параметры командной строки и key-файл. Параметры
командной строки переопределяют конфигурационный файл. Параметры приложения
находятся в группе `[Application]`, значения контекста плагинов — в `[Context]`.
Значения, переданные через `--context` или загруженные из `[Context]`,
блокируются, поэтому интерфейс не может переопределить централизованно заданные
значения.

Приоритет конфигурации (используется только первый найденный вариант; поля из
остальных вариантов не применяются):

1. Файл, указанный через опцию `--conf-file`.
2. Локальная конфигурация: `/etc/ready-set/config` и
   `/etc/ready-set/config.d/` (в алфавитном порядке).
3. Конфигурация поставщика: `/usr/share/ready-set/config` и
   `/usr/share/ready-set/config.d/` (в алфавитном порядке).

Когда загружается файл конфигурации (не через `--conf-file`), файлы из каталога
`config.d` также загружаются и объединяются с ним. Значения из файлов
`config.d` перезаписывают основной конфиг; значения из более поздних файлов
перезаписывают более ранние.

Пример конфигурационного файла находится [здесь](example/example.conf).

Параметры контекста отдельных плагинов описаны в их README.

### Опции

#### `apply-only`
Применить конфигурацию без запуска графического интерфейса. Недоступно в режиме
`existing-user`.

#### `can-close`
Всегда разрешать закрытие окна. В сборках с `nightly=true` окно всегда можно
закрыть. По умолчанию — `false`.

#### `conf-file`
Файл конфигурации приложения.

#### `context`
Значения контекста в формате `КЛЮЧ=ЗНАЧЕНИЕ`. Накопительную опцию можно указать
несколько раз. Списки строк разделяются запятыми, например
`--context keyboard.input-sources=xkb::us,xkb::ru`.

#### `force-layout`
Задать компоновку окна: `big`, `small` или `vertical`. По умолчанию выбирается
автоматически.

#### `force-mode`
Принудительно задать режим: `installer`, `initial-setup` или `existing-user`.
Доступно только в сборках с `nightly=true`. По умолчанию режим определяется
автоматически.

#### `fullscreen`
Запустить окно в полноэкранном режиме.

#### `height`
Высота окна. По умолчанию — `800`.

#### `installer`
Указать плагин установщика.

#### `resizable`
Разрешить изменять размер окна. По умолчанию — `false`.

#### `sandbox`
Запустить сценарий без изменений в системе.

#### `steps`
Список имён модулей плагинов шагов через запятую, например
`language,keyboard,user-passwdqc`.

#### `style`
Файл CSS-стилей, который будет добавлен к окну.

#### `version`
Вывести информацию о версии и завершить работу.

#### `width`
Ширина окна. По умолчанию — `1000`.

## Команды

Помимо обычного запуска Ready Set поддерживает:

- `generate-bash-completion` — вывести скрипт автодополнения Bash.
- `nothing-to-do` — вывести `0` в стандартный поток ошибок, если настройка не
  требуется, или `1` в противном случае.

## Тестирование

Используйте `--sandbox`, чтобы проверить сценарий без изменения системных
настроек, если плагины поддерживают этот режим. Запустите тесты проекта из
настроенного каталога сборки командой `meson test -C _build`.

## Сборка из исходного кода

Проект использует систему сборки Meson. Все доступные параметры сборки
перечислены [здесь](meson.options).

```sh
meson setup _build
meson compile -C _build
```
