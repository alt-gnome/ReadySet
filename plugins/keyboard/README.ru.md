# Плагин клавиатуры

Настраивает источники ввода GNOME и применяет итоговую раскладку X11 через
`org.freedesktop.locale1`.

## Настройки

| Переменная | Описание | По умолчанию |
| --- | --- | --- |
| `keyboard.preview-bin` | Имя программы предпросмотра раскладки XKB | `tecla` |

## Сохраняемые значения контекста

| Переменная | Описание |
| --- | --- |
| `keyboard.input-sources` | Выбранные источники ввода |
| `keyboard.additinal-layout-grp` | Дополнительный способ переключения раскладки; имя ключа совпадает с реализацией |
