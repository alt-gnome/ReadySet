# Плагин сети

Настраивает проводные, Wi-Fi- и модемные подключения через NetworkManager и
при применении изменений устанавливает имя хоста системы.

## Настройки

| Переменная | Описание | По умолчанию |
| --- | --- | --- |
| `network.simple` | Показывать шаг только когда NetworkManager не сообщает о полной связности | `false` |
| `network.required` | Требовать активное сетевое подключение для перехода дальше | `false` |

## Сохраняемые значения контекста

| Переменная | Описание |
| --- | --- |
| `network.hostname` | Имя хоста системы |
