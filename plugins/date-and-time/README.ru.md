# Плагин даты и времени

Настраивает часовой пояс и дату/время через `org.freedesktop.timedate1`.
Автоматическое определение часового пояса включено по умолчанию. Переключатель
автоматической установки даты и времени через NTP отображается только при
наличии свойства `CanNTP` у `org.freedesktop.timedate1`; если NTP недоступен,
дата и время выставляются вручную. Ручные значения применяются, только когда
соответствующая автоматическая настройка выключена.

## Настройки

| Переменная                         | Описание                                        | По умолчанию |
| ---------------------------------- | ----------------------------------------------- | ------------ |
| `date-and-time.automatic-timezone` | Автоматически определять часовой пояс           | `true`       |
| `date-and-time.automatic-datetime` | Автоматически выставлять дату и время через NTP | `true`       |

## Сохраняемые значения контекста

| Переменная               | Описание                                          |
| ------------------------ | ------------------------------------------------- |
| `date-and-time.timezone` | Выбранный часовой пояс                            |
| `date-and-time.datetime` | Выбранные дата и время, Unix timestamp в секундах |
