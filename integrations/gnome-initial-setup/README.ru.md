# Интеграция с GNOME Initial Setup

В этом каталоге находятся адаптированные из
[GNOME Initial Setup](https://gitlab.gnome.org/GNOME/gnome-initial-setup)
ресурсы интеграции: сеанс, D-Bus-служба, настройки dconf и описание системного
пользователя. Они позволяют запускать Ready Set в среде GNOME Initial Setup;
код приложения и плагины Ready Set находятся в других частях репозитория.
